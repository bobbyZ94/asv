# Angelverein Website

Eine SvelteKit-basierte Website für einen Angelverein mit Sveltia CMS als git-basiertes Content Management System.

## Entwicklung

```bash
npm install
npm run dev
```

Die Website läuft unter `http://localhost:5173`

## CMS

Das CMS ist unter `/admin` erreichbar (nach Integration in die Navigation).

## Build

```bash
npm run build
```

## Vorschau

```bash
npm run preview
```
